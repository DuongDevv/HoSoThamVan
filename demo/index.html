Chương 1: Giới Thiệu Tổng Quan Architecture

Trong các hệ thống Enterprise Backend hiện đại, việc lưu trữ và đọc tài liệu văn bản đòi hỏi tốc độ phản hồi cực nhanh dưới 50ms. Nút thắt cổ chai nằm ở khâu Full-Text Search (FTS) và cách phân trang.

Khi một file như PDF hay DOCX được người dùng upload lên server, hệ thống sử dụng Background Worker Process để tách chữ (Extract Text), loại bỏ ký tự lạ và đẩy nội dung vào Meilisearch Engine.

// Minh họa Background Worker bóc tách Text func ProcessDocumentWorker(docID string, fileBuffer []byte) error { text := extractTextFromPDF(fileBuffer) toc := generateTableOfContents(text) return indexToSearchEngine(docID, text, toc) }

Chương 2: Thiết Kế Database Schema PostgreSQL

Phân chia rõ ràng giữa dữ liệu Metadata (Tên tài liệu, tác giả, thể loại, ngày tạo) nằm ở Database quan hệ PostgreSQL và nội dung chữ chi tiết của từng chương/trang nằm ở hệ thống Search & Object Storage.

Chương 3: Tối Ưu Search Engine Với Meilisearch

Meilisearch cho phép tìm kiếm Tiếng Việt không dấu (Typo Tolerance). Ví dụ tìm từ "kien truc" vẫn ra đúng "Kiến Trúc Microservices".
